یک وب‌اپلیکیشن کاملاً رایگان و متن‌باز برای یادگیری زبان انگلیسی (ویژهٔ فارسی‌زبانان) — میزبانی‌شده روی **GitHub Pages**.

🌐 **نسخهٔ آنلاین:** <https://anishtayin.github.io/LearnEn/>

## ✨ امکانات

- 📚 **۲۶ درس گرامر و مهارت** در ۵ سطح A1 تا C1 با قاعده، جدول، مثال، تلفظ و تمرین تعاملی
- 📖 **۲۷۰+ واژهٔ پرکاربرد** با تلفظ IPA، معنی، مثال، دسته‌بندی و جستجو
- 🧠 **فلش‌کارت هوشمند** با مرور فاصله‌دار (Spaced Repetition)
- 📝 **۷۵+ سوال آزمون** سطح‌بندی‌شده + تعیین سطح ترکیبی با توضیح پاسخ
- 🗣️ **تلفظ و تمرین گفتار** با Web Speech API (شنیدن + تشخیص گفتار و امتیازدهی)
- 💬 **مکالمات روزمره** (کافه، هتل، پزشک، مصاحبهٔ شغلی و…)
- 🏆 **گیمیفیکیشن:** XP، استریک روزانه، نشان‌ها و پیگیری پیشرفت (ذخیرهٔ محلی در مرورگر)
- 🔐 **ورود با گیت‌هاب:** احراز هویت اختیاری برای اثبات اینکه کاربر یک حساب واقعی گیت‌هاب دارد، نه ربات یا حساب فیک
- 🌙 تم تاریک/روشن (بدون پرش رنگ هنگام بارگذاری)، طراحی شیشه‌ای مدرن، کاملاً ریسپانسیو و RTL
- ♿ **دسترسی‌پذیری:** پیمایش کامل با کیبورد، لینک «پرش به محتوا»، برچسب‌های ARIA و پشتیبانی از `prefers-reduced-motion`
- 📱 **PWA:** قابل نصب روی موبایل و دسکتاپ (manifest + آیکون‌ها)
- 🔎 **SEO:** متا تگ‌های Open Graph/Twitter، داده‌های ساختاریافته (JSON-LD)، `robots.txt` و `sitemap.xml`

هیچ داده‌ای به سرور ارسال نمی‌شود؛ همهٔ پیشرفت‌ها فقط در مرورگر کاربر ذخیره می‌شوند.

## 🔐 ورود با گیت‌هاب (احراز هویت)

در نوار بالای سایت دکمهٔ **«ورود با گیت‌هاب»** قرار دارد. با کلیک روی آن، یک **کد موقت** نمایش داده می‌شود؛ کاربر کد را در صفحهٔ تأیید گیت‌هاب وارد می‌کند و پس از تأیید، سایت اطلاعات عمومی پروفایل او (نام کاربری، آواتار، قدمت حساب، تعداد مخازن و دنبال‌کننده‌ها) را نمایش می‌دهد و حساب را به‌عنوان **«تأییدشده»** علامت می‌زند. این یعنی کاربر واقعاً صاحب آن حساب گیت‌هاب است.

### چطور کار می‌کند؟

از **OAuth Device Flow** گیت‌هاب استفاده می‌شود که برخلاف جریان عادی وب، به هیچ `client_secret` ای نیاز ندارد. گیت‌هاب به مسیرهای OAuth هدر CORS نمی‌دهد، بنابراین یک **پروکسی کوچک و بدون راز** (در پوشهٔ `oauth-proxy`) فقط دو درخواست را برای ما انجام می‌دهد؛ خواندن پروفایل نیز از `api.github.com` انجام می‌شود که از CORS پشتیبانی می‌کند. دسترسی درخواستی فقط `read:user` است (اطلاعات عمومی پروفایل) و توکن فقط در حافظهٔ نشست (sessionStorage) نگهداری می‌شود.

### راه‌اندازی (فقط یک‌بار)

1. **ساخت OAuth App:** در گیت‌هاب به `Settings → Developer settings → OAuth Apps → New OAuth App` بروید و یک اپ بسازید (نام و آدرس دلخواه). سپس در صفحهٔ همان اپ، گزینهٔ **«Enable Device Flow»** را فعال کنید و **Client ID** آن را کپی کنید.
2. **مستقرکردن پروکسی:** یک [Cloudflare Worker](https://workers.cloudflare.com) بسازید، محتوای فایل `oauth-proxy/worker.js` را در آن جای‌گذاری کنید و در بخش Variables متغیر `CLIENT_ID` را برابر Client ID مرحلهٔ قبل بگذارید. (اختیاری: متغیر `ALLOWED_ORIGIN` را برای محدودکردن دامنه‌ها تنظیم کنید.)
3. **اتصال سایت به پروکسی:** در فایل `js/auth.js` مقدار `CONFIG.proxy` را به آدرس Worker خود تغییر دهید (مثلاً `https://learnen-oauth-proxy.نام-شما.workers.dev`).

پس از این سه مرحله، دکمهٔ ورود به‌طور کامل فعال می‌شود. تا زمانی که این تنظیمات انجام نشده باشد، دکمه فقط راهنمای راه‌اندازی را نشان می‌دهد و بقیهٔ سایت بدون هیچ مشکلی کار می‌کند.

> 💡 برای تست محلی جریان OAuth، فایل `oauth-proxy/server.js` (بدون هیچ وابستگی) نیز کنار Worker قرار داده شده است.

## 🚀 انتشار روی GitHub Pages

انتشار به‌صورت خودکار انجام می‌شود:

1. در تنظیمات ریپو → **Pages**، گزینهٔ Source را روی **GitHub Actions** بگذارید (یک‌بار).
2. هر push به شاخهٔ `main` سایت را به‌صورت خودکار منتشر می‌کند (فایل `.github/workflows/pages.yml`).

ورک‌فلو طوری تنظیم شده که اگر Pages فعال نباشد، آن را خودش فعال کند (`enablement: true`) و از نسخه‌های به‌روز اکشن‌ها استفاده می‌کند تا خطاهای قدیمی (مانند خطای «Get Pages site failed» و هشدار Node.js 20) رخ ندهند.

## 📁 ساختار پروژه

```
index.html               صفحهٔ اصلی (SPA)
manifest.webmanifest     تنظیمات PWA (نصب روی دستگاه)
robots.txt / sitemap.xml  فایل‌های SEO
assets/                  آیکون‌های PWA و تصویر Open Graph
css/style.css            استایل‌ها و تم
js/data.js               داده‌ها: درس‌ها، واژگان، آزمون‌ها، مکالمات، نشان‌ها
js/app.js                منطق برنامه (درس، آزمون، فلش‌کارت، تلفظ، پیشرفت)
js/auth.js               ورود با گیت‌هاب (احراز هویت)
oauth-proxy/worker.js    پروکسی OAuth برای Cloudflare Workers
oauth-proxy/server.js    همان پروکسی به‌صورت محلی (فقط برای تست)
.github/workflows/       انتشار خودکار روی GitHub Pages
```
