# 🎓 LearnEn — یادگیری کامل زبان انگلیسی

یک وب‌اپلیکیشن کاملاً رایگان، آفلاین‌محور و بدون نیاز به ثبت‌نام برای یادگیری زبان انگلیسی (ویژهٔ فارسی‌زبانان) — میزبانی‌شده روی GitHub Pages.

🌐 **دمو:** https://anishtayin.github.io/LearnEn/

## ✨ امکانات
- 📚 **۲۶ درس گرامر و مهارت** در ۵ سطح A1 تا C1 با قاعده، جدول، مثال و تمرین تعاملی
- 📖 **۲۷۰+ واژهٔ پرکاربرد** با تلفظ IPA، معنی، مثال و دسته‌بندی + جستجو
- 🧠 **فلش‌کارت هوشمند** با مرور فاصله‌دار (Spaced Repetition)
- 📝 **۷۵+ سوال آزمون** سطح‌بندی‌شده + تعیین سطح ترکیبی با توضیح پاسخ
- 🗣️ **تلفظ و تمرین گفتار** با Web Speech API (شنیدن + تشخیص گفتار و امتیازدهی)
- 💬 **مکالمات روزمره** (کافه، هتل، پزشک، مصاحبه و…)
- 🏆 **گیمیفیکیشن:** XP، استریک روزانه، نشان‌ها و پیگیری پیشرفت (ذخیره در مرورگر)
- 🌙 تم تاریک/روشن، طراحی شیشه‌ای مدرن، کاملاً ریسپانسیو و RTL

## 🚀 استقرار روی GitHub Pages
1. در تنظیمات ریپو → **Pages** → Source را روی **GitHub Actions** بگذارید.
2. هر push به `main` به‌طور خودکار سایت را منتشر می‌کند (`.github/workflows/pages.yml`).

## 🛠️ اجرا به‌صورت محلی
```bash
python3 -m http.server 8080
# سپس http://localhost:8080
```
بدون هیچ وابستگی یا مرحلهٔ build — فقط HTML/CSS/JS خالص.

## 📁 ساختار
```
index.html        صفحهٔ اصلی (SPA)
css/style.css     استایل‌ها
js/data.js        داده‌ها: درس‌ها، واژگان، آزمون‌ها، مکالمات، نشان‌ها
js/app.js         منطق برنامه
```
